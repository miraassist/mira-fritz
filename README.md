# Mira FRITZ!Box

A Home Assistant integration for what a FRITZ!Box knows about the phone: its phone book, its answering machines and
who called.

- New messages and missed calls as sensors and events, for a dashboard, an automation or a voice satellite.
- Every message playable on any media player, a voice satellite too.
- Actions to list messages and calls, mark them as heard or seen, delete messages and read the phone book.

It is made for [Mira](https://github.com/miraassist/mira), a voice assistant on Home Assistant, and works without
her.

**Status:** built, not released yet ([docs/spec/fritz.md](docs/spec/fritz.md)).
